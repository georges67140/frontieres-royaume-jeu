# Atelier du guerrier — Les Rangs du Nord

Atelier de contrôle des mouvements, indépendant de la version d'entraînement à la racine du dépôt.

## Périmètre

Un guerrier de travail articulé : marche, halte, demi-tour, bouclier, attaque et réalignement avant charge. Commandes de ralenti, pause, avance image par image et vues de contrôle.

Le rendu 3D utilise Babylon.js 8.26.0. Une vue 2D de diagnostic identifiée reste disponible si le moteur externe ne se charge pas. Ce n'est pas le jeu complet et ce n'est pas un modèle graphique final.

## Validation avant publication

L'archive de l'atelier comporte 31 tests de logique et 22 contrôles d'interface en mode diagnostic. Ces résultats ne constituent pas une validation du rendu Babylon 3D ni un test matériel iPhone.

L'ajout de ce répertoire ne modifie pas l'ancien jeu ni ses images.
